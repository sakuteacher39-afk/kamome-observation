012026.10.27 — 日誌突然、千葉ロッテマリーンズのファンになりました。入口は、応援文化。そしてチョコ。
FIELD NOTE / 01日誌この記事の直接リンク ↗

来年からプロ野球を楽しんでみたい。せっかくなら、強い弱いではなく、何か一つ尖った球団を応援したい。そんな話をしていたら、千葉ロッテマリーンズにたどり着いた。

熱のこもった、独特の応援。風に左右されるという海沿いの球場。なんだか妙に気になる球団だった。

でも、最後に背中を押したのは別の話だ。「ロッテが優勝したら、チョコが安くなるんじゃないか？」。

理由は不純。応援は本気。

我ながら、かなり変な入口だと思う。でも、野球を好きになるのに立派な理由が必要とも思わない。

この場所は、玄人が戦術を断言するブログではない。知らない選手の名前を覚えたり、補強の意味を調べたり、試合に一喜一憂したり。その過程を残す、ひとりの新米ファンの観察日記だ。

2027年3月26日。開幕を待つ時間から、もうファン活動は始まっている。

022026.10.27 — 観察2026年のマリーンズは、どんなチームだった？勝ち負けの数字から、ひとまず始める。
FIELD NOTE / 02観察この記事の直接リンク ↗

新米ファンが最初に押さえた数字は、2026年の最終成績。143試合・63勝77敗3分、勝率.450。パ・リーグ5位。

はっきり言って、好成績とは呼べない。それでも、ここで「来年は優勝だ！」と唱えるだけでは、チームを知ったことにならない気がする。

「去年はできなかったことが、今年はできるようになった」。そんな発見ができれば、勝敗のほかにも応援する楽しみが増えそうだ。

042026.10.27 — 調査マリーンズが優勝したら、チョコは安くなるのか？ファンになった理由を、まじめに検証する。
FIELD NOTE / 04調査この記事の直接リンク ↗

マリーンズを応援することになった、ちょっと大事な疑問。優勝したら、ロッテのお菓子は安くなるのか。

2005年10月14日付のセブン＆アイの発表を読むと、千葉県内のセブン-イレブンで、ガーナ、パイの実、コアラのマーチなど6品の菓子詰め合わせ（合計890円相当）を777円で販売する企画が告知されていた。

ただし、ここは訂正しておきたい。その詰め合わせは、優勝の有無にかかわらず販売される応援企画だった。一方で、おでん70円均一は優勝決定を条件にしていた。

「優勝したら必ずチョコが安くなる」わけではない。

それでも2005年の日本一の後には、記念商品「マリーンズ コアラのマーチ」「マリーンズガム」が発売されている。勝利とお菓子の間には、ちょっと楽しい歴史がある。

2027年に何かセールがあるかは、当然まだわからない。期待は期待として、発表を楽しみに待とう。

2005年の販売価格は当時の資料に基づくものです。現在の価格や将来のセール予定ではありません。

052026.10.30 — 秋季キャンプ都城の秋が始まった。みしょーが語った、5位からの再出発。初めて追いかける秋季キャンプ。その初日の記録。
FIELD NOTE / 05秋季キャンプこの記事の直接リンク ↗

2026年10月30日。千葉ロッテマリーンズの秋季キャンプが、宮崎県都城市で始まった。

場所は、コアラのマーチスタジアム。

球場の名前からして、チョコをきっかけにマリーンズファンになった人間には妙な親近感がある。

とはいえ、キャンプというものを、つい最近までよく分かっていなかった。シーズンが終わっても、選手たちは練習するらしい。しかも、かなり本格的に。

その程度の知識から始まる、初めての秋季キャンプ観察である。

01｜みしょーが「優勝」を口にした。

初日の歓迎セレモニーで、選手を代表して挨拶したのは西川史礁選手。

「にしかわ・みしょう」。

つい最近、この名前の読み方を覚えたばかりだ。今はもう、親しみを込めて「みしょー」と呼んでいる。

そのみしょーが、2026年のチーム成績を振り返った。マリーンズは今季5位。悔しさの残る結果だったことを認めたうえで、来年こそ優勝を報告できるように頑張ると語った。

キャンプでは体を鍛え、選手全員で成長することを目指すという。

まだ今年の試合を追いかけていなかった新米ファンにとって、5位という結果の重みを実感できているとは言い難い。

でも、選手たちが来年に向けて動き出す、その最初の日には立ち会えた。

ニュース越しだけど。

これはこれで、なかなかいいタイミングでファンになったのかもしれない。

02｜秋の練習は、来年のためにある。

地元テレビ局の報道によると、初日はキャッチボールや守備練習に取り組む選手たちの姿が見られたという。

また、球団広報によれば、サブロー監督のキャンプでは練習量を重視する方針を続けながら、より実戦を意識した内容に発展させているそうだ。

まだ、みしょーがどんな打撃練習をしたのか、石垣元気投手がブルペンで何球投げたのか、といった詳しいところまでは確認できていない。

だから、この段階で「誰が成長した」とは書けない。

その答えは、これからの練習や来春の姿を見て考えよう。

秋に何を変えようとしていたのか。それが来年の試合でどう表れるのか。

そうやって見ていくのが、キャンプ観察の楽しみ方なのだと思う。

03｜そして、やっぱりチョコの話。

キャンプ初日、球団からもう一つニュースが出た。都城限定の「キャンプ地都城のマーチ」が配布されるらしい。

11月3日と14日には、選手によるお渡し会も予定されている。各日先着200個。

チームの強化合宿を調べていたはずなのに、結局コアラのマーチの情報にたどり着いてしまった。

どうやら、この観察日記は今後も野球とチョコの間を行ったり来たりすることになりそうだ。

04｜最初の一日を記録する。

秋季キャンプは11月15日まで続く。

明日からは、みしょーの打撃、石垣元気の投球、山口航輝の取り組みに注目していきたい。

もちろん、名前も知らなかった選手に興味を持つことだってあるだろう。

まだ分からないことだらけだ。でも、これから少しずつ覚えていけばいい。

2027年の開幕を迎える頃には、今日のニュースをもっと違う気持ちで読み返せるかもしれない。

都城の秋が始まった。
そして、新米ファンの観察も始まった。

理由は不純。応援は本気。

062026.11.01 — 秋季キャンプ「トッポ」からバックスクリーンへ。みしょーが見せた秋の手応え。130メートル級の一発。その裏には、ちょっと面白い練習があった。
FIELD NOTE / 06秋季キャンプこの記事の直接リンク ↗

秋季キャンプ3日目。

今日も都城では選手たちが練習している。

でも、最初にニュースを調べたときは、あまり目立った動きが見つからなかった。

「今日は特に進展なしかな」

そんなことを思っていたら、とんでもない。

みしょーが、バックスクリーンにホームランを打っていた。

しかも、ただの一発ではない。

その裏には、何ともマリーンズらしい、そして個人的には見逃せない練習があった。

01｜130メートル級の一発。

11月1日、都城のコアラのマーチスタジアムでは「ライブBP」が行われた。

ライブBPとは、投手が実際に打者に向かって投げる、実戦に近い打撃練習のこと。

まだ野球の専門用語に慣れていない身としては、こういう言葉も一つずつ覚えていく。

この日マウンドに立ったのは、中森俊介投手。

打席には、山口航輝選手と西川史礁選手が入った。

そして、みしょー。

中森投手の直球を捉え、バックスクリーンへ豪快な一発を放った。

デイリースポーツでは約130メートルの打球として報じられている。

さらに、その後のゲーム形式の練習でも左翼ポール直撃の本塁打を放ったという。

練習とはいえ、一日に二度の大きな当たり。

まだプロ野球を追い始めたばかりの新米ファンには、十分すぎるほどワクワクするニュースだ。

もちろん、これは公式戦の本塁打記録に加わるものではない。

でも、秋の練習で何かをつかみ始めているのなら、来年が楽しみになる。

02｜みしょーの課題は「もっと遠くへ」。

今回、個人的に一番面白かったのは、ホームランそのものよりも、その背景だった。

みしょーは、この秋に打球の飛距離を伸ばすことをテーマに練習していたらしい。

ZOZOマリンスタジアムでの秋季練習では、ロングティーと呼ばれる打撃練習に取り組んでいた。

しかも目標は、左翼ポールの上部。

そこには、ロッテのお菓子「トッポ」の絵柄があるという。

その場所を狙って打つ、通称「トッポポールチャレンジ」。

……待ってくれ。

俺がチョコをきっかけに応援を始めた球団で、選手がトッポを目標に打撃練習しているだと？

なんという偶然。

いや、ロッテだから必然なのかもしれない。

ともあれ、ただ闇雲に遠くへ打っているわけではない。

打球に角度をつけ、もっと遠くまで飛ばすために、狙いを定めて繰り返し練習してきた。

そして今日、実戦に近い練習でも大きな当たりが出た。

みしょー本人も、理想に近い打撃ができたと手応えを語っている。

これが来季の公式戦でも再現できるかは、まだ分からない。

でも、「何を練習して、どんな結果が出たのか」を初めて具体的に知ることができた。

秋季キャンプを追う面白さが、少し分かってきた気がする。

03｜中森も、山口も。そして侍ジャパンへ。

この日のライブBPでは、山口航輝選手も2本の安打性の打球を放った。

一方、登板した中森俊介投手は計25球を投げ、安打性の当たりは4本。

中森投手は自身の投球内容に課題を感じている様子だったという。

同じ練習でも、打者が手応えを感じる一方で、投手には反省点が残る。

こういうところも野球の面白さなのだろう。

そして、みしょーは11月1日で都城キャンプでの練習参加を終え、翌日から侍ジャパンの合宿へ合流する予定だ。

そうか。

覚えたばかりの「みしょー」は、日本代表にも選ばれている選手なんだな。

都城での練習はひと区切り。

次は、日本代表としてどんな姿を見せてくれるのか。

04｜秋の記録を、春に読み返そう。

まだ、みしょーの打撃を自分の目で見たことはない。

130メートルという飛距離も、ニュースで知った数字だ。

それでも今日、一つ覚えたことがある。

選手が何を変えようとしているのかを知ると、練習のニュースまで面白くなる。

ただ「ホームランを打った」で終わらせず、そこに至るまでの取り組みを記録しておきたい。

来年の春、みしょーがどんな打球を放っているのか。

そのとき、今日のニュースを思い出せたらいい。

そしてもう一つ。

トッポを見るたびに、たぶんこの日のホームランを思い出すようになる。

ますますロッテのお菓子から離れられなくなってしまった。

理由は不純。応援は本気。

072026.11.08 — 秋季キャンプみしょーが打った。マリーンズが負けた。新米ファン、初めての複雑な一日。11月7日、侍ジャパン対ロッテ。うれしいのに、悔しい。
FIELD NOTE / 07秋季キャンプこの記事の直接リンク ↗

11月7日。宮崎で、侍ジャパンと千葉ロッテマリーンズが練習試合をした。

最初に結果を見たとき、ちょっと困った。

侍ジャパン10点。マリーンズ4点。

ああ、マリーンズが負けたのか。

ところが、代表側で活躍した選手の名前を見て、さらに困ることになった。

西川史礁、2安打2打点。

みしょーが打った。うれしい。

でも、打たれたのはマリーンズだ。

……こういうとき、新米ファンはいったいどんな顔をすればいいんだろう。

01｜敵の3番が、うちのみしょー。

この日、みしょーは侍ジャパンの「3番・左翼」で先発した。

2回に右前適時打。6回には右中間への三塁打で、さらに1打点。合わせて2安打2打点。

ほんの少し前、名前の読み方を覚えたばかりの選手が、日本代表のユニフォームで結果を残している。

いや、これはうれしい。

秋季キャンプではバックスクリーンへの大きな当たりもあった。あの練習のあとに、代表の試合でも打った。

もちろん、練習試合の結果だけで「来季は大丈夫」とは言えない。

でも、何かをつかもうとしている選手を追う楽しさは、確実に増している。

ただ一つ、問題がある。

今日の対戦相手は、マリーンズだったのだ。

02｜それでも、マリーンズも黙っていなかった。

試合は初回に5失点、2回にも3失点。序盤から苦しい展開になった。

ロッテの記録には3つの失策が残っている。

投手が打たれたことも事実。でも、守備のミスも重なった試合を、単純に「投手が悪かった」の一言で片づけるのは違う気がする。

そんな中、3回に山本大斗がソロホームランを放った。

相手は日本代表の投手陣。

大差の試合でも、マリーンズ側からちゃんと一発が飛び出した。

藤原恭大は2安打1打点。7回にはチームで3点を返した。

最終的には4対10。

完敗と言っていいスコアだと思う。それでも、若い選手たちがどんな結果を残したのか、一人ずつ見てみると少し景色が変わる。

勝敗だけでは、見落としてしまうものがあるらしい。

03｜櫻井ユウヤ、4打席で4三振。

そして、もう一人。

キャンプ2日目に名前を覚えた、櫻井ユウヤ。

サブロー監督が将来の長距離砲として期待しているという、あの若手だ。

この日は「6番・三塁」で先発。

結果は、4打数無安打、4三振。

見逃し三振が2つ、空振り三振が2つ。公式記録には、そう残っている。

なかなか厳しい。

でも、ここで「まだ通用しない選手だ」と決めつけるのは早すぎるだろう。

日本代表の投手を相手にした一試合で、選手の将来が決まるわけじゃない。

むしろ、この4三振を覚えておきたい。

来年、再来年、櫻井が大きな打球を飛ばすようになったら。

「そういえば、秋には4三振していたな」と笑って振り返れるかもしれない。

成功した日だけじゃなく、苦戦した日も残す。

それも観察日記の仕事だと思う。

04｜翌日、またマリーンズの選手が打った。

翌11月8日、侍ジャパンは広島とも練習試合を行った。

結果は5対1で侍ジャパンの勝利。

みしょーはこの日も2安打を記録。山口航輝は4番で先発し、初回に先制の適時打を放った。

さらに中森俊介も登板し、1イニングを無失点。3人で打ち取った。

代表側にいるマリーンズの選手たちは、ちゃんと前へ進んでいる。

一方、都城で鍛えている若手たちにも、それぞれの課題がある。

同じチームの選手でも、秋の過ごし方も、今見えている景色も違う。

その両方を追いかけられるのは、なかなかぜいたくなことなのかもしれない。

05｜今日は、ちょっと複雑な日だった。

マリーンズが負けたのは悔しい。

みしょーが打ったのはうれしい。

山本のホームランには期待が膨らむし、櫻井の4三振は気になる。

いろんな感情が、たった一試合に詰まっている。

ファンになる前なら、きっと10対4というスコアだけを見て終わっていただろう。

でも今は違う。

誰が打ったのか。誰が打てなかったのか。そこから何が始まるのか。

そんなことまで気になってしまう。

どうやら、少しずつマリーンズファンになっているらしい。

理由は不純。応援は本気。
